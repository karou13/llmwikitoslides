# 研究模型與資料簡報：產出資料夾

本資料夾存放 `research-model-deck` loop 的產出。Loop 規格見 `.claude/skills/research-model-deck/SKILL.md`。

- `sources.md`：[1] 檢索結果
- `cards/`：[2] 證據卡，一篇一張
- `outline.md`：[3] 大綱
- `drafts/`：[4] 逐頁稿
- `deck.html`：簡報成品
- `report.md`：每一輪檢查結果與修正紀錄
- `review-round-N.md`：第 N 輪 AI 審查意見
- `katex/`：簡報公式用的 KaTeX 樣式與字型
